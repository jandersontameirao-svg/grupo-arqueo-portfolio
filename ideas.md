# Brainstorm de Design — Portfólio Digital Grupo Arqueo

## Contexto
Portfólio digital navegável premium para o Grupo Arqueo (10 anos). Home como centro da experiência, páginas internas como capítulos. Estética editorial, sofisticada, contemporânea. Paleta: laranja/terracota, vinho, azul institucional, grafite, bege areia.

## Ideia 1 — "Estratos Editoriais"

**Design Movement:** Neo-Editorial Minimalista inspirado em revistas de arquitetura e design contemporâneo (Kinfolk, Cereal Magazine).

**Core Principles:**
1. Composição assimétrica com blocos de conteúdo que remetem a camadas arqueológicas
2. Tipografia como elemento gráfico dominante — títulos enormes, bold, com recuos ousados
3. Espaço negativo generoso como elemento ativo de sofisticação
4. Transições de página que simulam o "virar de página" de uma publicação editorial

**Color Philosophy:** O laranja/terracota (#EE7501) como cor de energia e destaque pontual — nunca dominante, sempre cirúrgico. Grafite (#2A2A2A) como base textual. Bege areia (#F3EFEA) como fundo editorial. Vinho (#861720) para acentos de autoridade. Azul (#2C7EB3) para elementos técnicos e links.

**Layout Paradigm:** Grid editorial assimétrico com colunas desiguais (40/60, 30/70). Blocos de conteúdo com margens generosas e alinhamento à esquerda. Índice da Home em formato de sumário editorial com numeração grande.

**Signature Elements:**
1. Linhas finas horizontais como separadores (remetendo a estratos de escavação)
2. Numeração grande em laranja nos capítulos (01, 02, 03...)
3. Barra lateral sutil com indicador de progresso na navegação

**Interaction Philosophy:** Transições suaves e lentas. Hover revela informação adicional com fade elegante. Scroll revela conteúdo com timing editorial.

**Animation:** Entrada de elementos com fade-up sutil (200ms delay entre itens). Parallax leve em imagens de fundo. Contadores numéricos com easing suave.

**Typography System:** Garet Bold para títulos (display, 48-96px). Montserrat Light para corpo (16-18px, line-height 1.7). Montserrat Medium para subtítulos e labels.

## Ideia 2 — "Território e Camadas"

**Design Movement:** Brutalismo Refinado com influências de design suíço e cartografia contemporânea.

**Core Principles:**
1. Contrastes fortes entre seções — alternância entre fundos escuros (grafite) e claros (off-white)
2. Elementos gráficos geométricos inspirados em mapas topográficos e cortes estratigráficos
3. Tipografia monumental em seções de impacto
4. Cards do índice como "territórios" visuais com bordas e texturas distintas

**Color Philosophy:** Alternância dramática entre seções escuras (grafite #2A2A2A com texto claro) e seções claras (bege #F3EFEA com texto escuro). Laranja (#EE7501) como cor de ação e destaque. Vinho (#861720) para gravidade institucional. Azul (#2C7EB3) para dados e tecnologia.

**Layout Paradigm:** Full-bleed sections que ocupam 100vw. Grid de cards no índice com proporções variadas (alguns maiores, outros menores) criando hierarquia visual. Páginas internas com layout de duas colunas assimétricas.

**Signature Elements:**
1. Linhas topográficas sutis como textura de fundo
2. Blocos coloridos laterais como marcadores de capítulo
3. Transição diagonal entre seções (clip-path)

**Interaction Philosophy:** Cards do índice com hover que expande e revela preview do conteúdo. Scroll-triggered animations com stagger. Cursor personalizado sutil.

**Animation:** Seções entram com slide lateral. Cards do índice com scale sutil no hover (1.02). Números com contagem animada. Barras de progresso animadas.

**Typography System:** Garet ExtraBold para headlines monumentais (64-120px). Montserrat Light para corpo. Garet Medium para subtítulos e navegação.

## Ideia 3 — "Galeria Institucional"

**Design Movement:** Design de Galeria de Arte / Museum-grade Digital Experience, inspirado em sites de museus como MoMA e Fondation Cartier.

**Core Principles:**
1. Cada página como uma "sala" de exposição com identidade visual própria mas coerente
2. Fundo predominantemente off-white com elementos visuais como "obras" em destaque
3. Navegação minimalista que desaparece para dar protagonismo ao conteúdo
4. Imagens e dados tratados como peças de exposição com molduras sutis

**Color Philosophy:** Off-white (#F9F8F6) como "parede da galeria". Grafite (#2A2A2A) para tipografia principal. Laranja (#EE7501) como cor de curadoria — aparece em detalhes, bordas, ícones. Vinho (#861720) para momentos de solenidade. Azul (#2C7EB3) para elementos interativos.

**Layout Paradigm:** Layout centralizado com max-width generoso (1400px). Conteúdo disposto como em uma timeline vertical. Índice da Home como grid de "quadros" com proporções áureas.

**Signature Elements:**
1. Molduras finas ao redor de cards e imagens (1px, cor laranja ou grafite)
2. Labels tipográficos pequenos em uppercase como legendas de museu
3. Transições de página com fade branco (como entrar em outra sala)

**Interaction Philosophy:** Minimalismo interativo — poucos elementos, mas cada um com feedback refinado. Hover com bordas que mudam de cor. Click com transição suave de sala.

**Animation:** Page transitions com fade (300ms). Elementos entram com opacity + translateY sutil. Imagens com lazy-load elegante (blur-up). Números com typewriter effect.

**Typography System:** Garet para títulos (clean, 40-72px). Montserrat Light para corpo (16px, tracking amplo). Labels em Montserrat Medium uppercase (11-12px, letter-spacing 2px).

## Decisão

**Escolha: Ideia 1 — "Estratos Editoriais"**

Esta abordagem é a mais alinhada com o briefing do portfólio digital premium navegável. O conceito editorial assimétrico evita a aparência de site corporativo comum, a numeração de capítulos reforça a ideia de "apresentação navegável", e o uso sofisticado de espaço negativo transmite o alto valor percebido desejado. A metáfora dos estratos arqueológicos conecta forma e conteúdo de maneira inteligente.
