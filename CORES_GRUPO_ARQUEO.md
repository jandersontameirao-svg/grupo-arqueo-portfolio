# Paleta de Cores - Grupo Arqueo

## Cores Principais

- **Laranja Primário**: #EE7501 (laranja vibrante)
- **Vermelho Vinho**: #8B1F2E ou #861720 (vermelho profundo/marrom-avermelhado)
- **Amarelo Ouro**: #FFC107 ou #FFD700 (amarelo dourado)
- **Branco**: #FFFFFF
- **Cinza Claro**: #FAFAF9 ou #F5F5F5

## Cores Secundárias (Empresas)

- **ArqueoProject**: Vermelho vinho (#8B1F2E)
- **ArqueoGIS**: Azul (#2C7EB3)
- **ArqueoOcean**: Azul claro/Ciano
- **ArqueoEduc**: Vermelho/Marrom
- **ArqueoRede**: Laranja (#EE7501)
- **SIGEPA Plus**: Laranja (#EE7501)

## Notas
- Paleta moderna, sofisticada
- Cores quentes predominam (laranja, vermelho)
- Branco e cinza para respiro visual
- Amarelo ouro para destaque e ênfase
